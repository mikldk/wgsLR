# Enumeration of possibilities under Hd for sample-dependent error probabilities, \$w_D\$ and \$w_S\$

Enumeration of possibilities under Hd for sample-dependent error
probabilities, \$w_D\$ and \$w_S\$

## Usage

``` r
d_formulas_Hd_wDwS
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 256
rows and 24 columns.
