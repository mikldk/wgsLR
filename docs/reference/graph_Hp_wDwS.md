# Graph for enumeration of possibilities under Hp for sample-dependent error probabilities, \$w_D\$ and \$w_S\$

Graph for enumeration of possibilities under Hp for sample-dependent
error probabilities, \$w_D\$ and \$w_S\$

## Usage

``` r
graph_Hp_wDwS
```

## Format

An object of class `tbl_graph` (inherits from `igraph`) of length 10.
